# アプリのアイコン

ここに次の 2 つのファイルを置くと、ビルドしたアプリに組み込まれます（どちらも任意です。ないときは「IBS」と書いた仮のアイコンになります）。

| ファイル | 使われる所 | 作り方の目安 |
|---|---|---|
| `app.png` | ウィンドウのタイトルバー・タスクバー、「ヘルプ → バージョン情報」 | 正方形、512×512 か 256×256、背景は透明 |
| `app.ico` | エクスプローラーでの `IgusaBmsonStudio.exe` / `igusa-cli.exe` のアイコン、デスクトップのショートカット | 16・24・32・48・64・256 の各サイズを 1 つにまとめた ico |

- ファイル名は小文字で `app.png` / `app.ico` にしてください
- 置いた後は CMake の構成をやり直してください（Qt Creator なら「ビルド → CMake の再実行」、コマンドなら `cmake --preset ...` をもう一度）。構成のときにファイルがあるかを調べるためです
- ico は、png から [ImageMagick](https://imagemagick.org/) で作れます

```bat
magick app.png -define icon:auto-resize=256,64,48,32,24,16 app.ico
```
