# 譜面タブの操作（現在の実装）

- 対象: v0.13.2 時点の `ChartEditorWidget`（譜面ビュー）、`ChartMinimap`、`BgaPanel`
- 目的: 今の操作の仕様を洗い出し、直したい動作を番号で指定できるようにする
- 各行の番号（`A-01` など）は、この文書の中だけの通し番号。直したい行を番号で指定してください

## 0. 前提

### 列の並び（左から）

| 列 | 中身 | 縦の位置の意味 |
|---|---|---|
| 小節番号（左端 34px） | 小節線と番号。見出しには今のモード（割当 / 切断） | — |
| BPM 等（64px） | BPM 変更・STOP・拍子の表示 | — |
| レーン | モード定義のレーン（beat-7k は SC, 1〜7） | ノーツの頭の位置（下が曲の頭） |
| BGM 列 | レーン外の x（beat-7k は 9 以上）。「BGM 列を折りたたむ」で消える | 同上 |
| BGA / LYR / POOR | BGA イベント | イベントの位置 |
| 素材列 | 素材ごとの切断点（スライスの頭） | 切断点の位置 |
| 密度（右端 28px） | 小節ごとのノーツ数 | — |
| ミニマップ（別部品） | 曲全体の縮図 | 曲全体 |

### モード

| モード | 切り替え | 違い |
|---|---|---|
| 割当モード（既定） | Tab / 譜面メニュー | 素材列の切断点をドラッグすると「レーンへの割り当て」 |
| 切断点モード | Tab / 譜面メニュー | 素材列の切断点をドラッグすると「切断点の移動」、空いた所のダブルクリックで切断点を追加 |

ノーツ・BGA・右クリック・キーの操作は、どちらのモードでも同じ。

### 選択の状態

| 種類 | 表示 | 一緒に変わるもの |
|---|---|---|
| 選択中のノーツ | 白い枠 | ノーツをクリックすると、そのノーツの切断点が「選択中の切断点」になる |
| 選択中の切断点 | 白い枠 | 切断点をクリックすると、その切断点のノーツが「選択中のノーツ」になる |
| 選択中の BGA イベント | 白い枠 | ノーツ・切断点の選択とは別に持つ |
| カーソル | 黄色の横線 | 貼り付け先・曲の再生開始位置 |

「クリックしたスライスを波形に表示する」がオンのときは、切断点が選ばれるたびに下の波形がその配置へ切り替わる（`focusCuts`）。

### 共通のきまり

- 押してから 3px 以上動くと「ドラッグ」、それ未満は「クリック」として扱う（移動量は縦・横の合計）
- 横か縦かは区別していない。ドラッグの種類は **押した物** で決まり、離した位置の **列** と **縦の位置** をそれぞれ使う
- 見出しの行（上 22px）での左ボタンは何もしない
- 当たり判定: ノーツは頭から上へ 6px（ロングノーツは尾まで）＋4px。切断点は上下 4px 以内で最も近いもの。BGA イベントは位置から上へ 14px
- スナップ: ツールバーの単位。Shift で 4 倍細かく、Alt でスナップなし（下では「スナップ」と書く）

## 1. ノーツ（レーン・BGM 列）

| 番号 | 状態 | 操作 | 今の動作 |
|---|---|---|---|
| A-01 | 未選択 / 選択中（1 つだけ選択） | クリック | そのノーツだけを選ぶ（他の選択は外れる）。その切断点を選ぶ。スライスを鳴らし、カーソルを切断点の位置へ動かす（v0.13.1 で追加） |
| A-02 | 未選択 | Ctrl+クリック | 選択に足す。鳴らさない |
| A-03 | 選択中 | Ctrl+クリック | 何も変わらない（選択から外れない） |
| A-01b | 複数選択中のうちの 1 つ | クリック | 選択はそのまま。鳴らす・カーソルを動かす（v0.13.2）|
| A-04 | 1 つだけ選択 / 未選択 | 横ドラッグ → レーン / BGM 列で離す | そのレーンへ移す（縦の位置＝タイミングは変わらない） |
| A-04b | 複数選択中のうちの 1 つ | 横ドラッグ | 選択中のノーツをまとめて、並びを保ったまま同じ列数だけずらす（押したノーツが離した位置に最も近いレーンへ）。どれか 1 つでもレーン・BGM 列の外へ出る分は端で止める（割り当ては外れない）。ドラッグ中は移動先に表示する（v0.13.2） |
| A-05 | 1 つだけ選択 / 未選択 | ドラッグ → レーン・BGM 列の外（素材列・BGA 列・小節番号・BPM 等・密度・画面の外）で離す | 割り当てを外す（ノーツを消し、スライスは素材列の BGM に戻る）。ドラッグ中はノーツが薄くなる（v0.13.1 で追加） |
| A-06 | 任意 | 縦ドラッグ（同じレーンのまま離す） | 何も変わらない（タイミングは割当モードでも切断点モードでも動かせない） |
| A-07 | 任意 | ノーツの上端（通常ノーツは四角の上辺、ロングノーツは尾）をドラッグ | A-04 / A-04b / A-05 と同じ（レーンの移動。縦方向は無視してタイミングは変えない）（v0.13.2。以前は長さの変更） |
| A-08 | 任意 | Shift+ドラッグ（どこを掴んでも） | ロングノーツの長さを変える（離した位置までの長さ、スナップ。下へ引いて 0 にすると通常ノーツ）。動くのは押したノーツ 1 つだけ |
| A-09 | 任意 | ダブルクリック | A-01 が 2 回起きるだけ（ダブルクリック自体の動作はない） |
| A-10 | 任意 | 右クリック | 選択は変えずに、テンポのメニュー（§6）を出す |
| A-11 | 任意 | Shift+ダブルクリック | ロングノーツ ⇔ 通常ノーツを切り替える。ロングノーツにするときの長さは、スライスの終わり（同じ配置の次の切断点）まで。配置の最後のスライスは 1 拍。同じレーンの次のノーツがあれば、スナップ 1 つ分手前で止める（入らないときはメッセージ）。押したノーツだけが対象（v0.13.2） |

## 2. 素材列の切断点

| 番号 | モード | 状態 | 操作 | 今の動作 |
|---|---|---|---|---|
| B-01 | 両方 | 未選択 / 選択中（1 つだけ選択） | クリック | その切断点だけを選ぶ。そのノーツを選ぶ。スライスを鳴らし、カーソルを切断点へ動かす |
| B-02 | 割当 | 複数選択中のうちの 1 つ | クリック | 選択はそのまま。鳴らす・カーソルを動かす。ノーツの選択は押した切断点のノーツだけになる |
| B-03 | 両方 | 未選択 | Ctrl+クリック | 選択に足す。鳴らさない |
| B-04 | 両方 | 選択中 | Ctrl+クリック | 選択から外す。鳴らさない |
| B-05 | 割当 | 任意（Ctrl なし） | ドラッグ → レーン / BGM 列で離す | そのレーンに割り当てる。押した切断点が選択中なら、選択中の切断点すべてを割り当てる。ドラッグ中は置く位置を点線で示す。割り当て後に次の切断点へは進まない |
| B-06 | 割当 | 任意 | ドラッグ → レーン・BGM 列の外で離す | 何もしない |
| B-07 | 切断点 | 先頭以外 | ドラッグ（縦） | 切断点を動かす（スナップ）。横の位置は無視。手動の切断点になる |
| B-08 | 切断点 | 配置の先頭（白い点） | ドラッグ | 何もしない（選択と試聴だけ） |
| B-09 | 割当 | 任意 | ダブルクリック | B-01 が 2 回起きるだけ |
| B-10 | 切断点 | — | 素材列の空いた所をダブルクリック | その位置（スナップ）に切断点を追加し、選ぶ。その位置より前で始まる最後の配置に入る |
| B-11 | 両方 | — | 右クリック | テンポのメニュー（§6） |

## 3. 空いた所（ノーツ・切断点・BGA イベントのない所）

レーン・BGM 列・素材列の空き、小節番号の列、BPM 等の列、密度の列のどこでも同じ。BGA 列は §4。

| 番号 | 操作 | 今の動作 |
|---|---|---|
| C-01 | クリック | カーソルをその位置へ動かす（スナップ）。ノーツと切断点の選択を外す |
| C-02 | Ctrl+クリック | カーソルを動かす。選択はそのまま |
| C-03 | ドラッグ | 範囲選択（白い半透明の四角）。四角に入ったノーツの中心・切断点を選ぶ（前の選択は外れる） |
| C-04 | Ctrl+ドラッグ | 範囲選択で選択に足す |
| C-05 | ダブルクリック | C-01 が起きるだけ（切断点モードの素材列だけ B-10） |
| C-06 | 右クリック | テンポのメニュー（§6） |

## 4. BGA / LYR / POOR 列

| 番号 | 状態 | 操作 | 今の動作 |
|---|---|---|---|
| D-01 | イベント | クリック | そのイベントを選ぶ（ノーツ・切断点の選択は変えない） |
| D-02 | イベント | ドラッグ（縦） | イベントを動かす（スナップ）。横は無視。同じ列の別のイベントと重なる位置ではエラー |
| D-03 | 空いた所 | クリック | イベントの選択を外し、カーソルを動かす（範囲選択はできない） |
| D-04 | 空いた所 | ダブルクリック | 右の一覧で選んだ画像を置く（スナップ）。画像を選んでいなければメッセージだけ |
| D-05 | イベント | ダブルクリック | D-01 → 一覧で選んでいる画像でその位置を置き換える（同じ画像なら変わらない） |
| D-06 | 任意 | 右クリック | テンポのメニュー（§6） |
| D-07 | イベント選択中 | Delete | イベントを消す |

ノーツ・切断点を押したときは、BGA イベントの選択は外れる。

## 5. キー（譜面ビューにフォーカスがあるとき）

| 番号 | キー | 今の動作 |
|---|---|---|
| E-01 | 1〜9 | 選択中の切断点（なければ選択中のノーツの切断点）を、鍵盤の左から n 番目のレーンに割り当てる。ノーツがある切断点はノーツを移す。切断点が 1 つで「割り当てたら次へ進む」がオンなら、同じ素材の次の切断点へ進んで鳴らす |
| E-02 | S | スクラッチに割り当てる（E-01 と同じ規則） |
| E-03 | 0 / Backspace | 選択中の切断点・ノーツの割り当てを外す。切断点が 1 つで「次へ進む」がオンなら次へ |
| E-04 | Delete | BGA イベントを選んでいればそれを消す。切断点モードで切断点を選んでいれば切断点を消す（ノーツのある切断点・先頭は残す）。それ以外は選択中のノーツを消す |
| E-05 | ↑ / ↓ | 同じ素材の次 / 前の切断点へ（何も選んでいなければ、カーソル以降の最初の切断点を全素材から）。選んで鳴らし、見えなければスクロール |
| E-06 | Enter | 選択中の最初の切断点を鳴らす |
| E-07 | Space | 曲の再生 / 停止（カーソルから） |
| E-08 | Tab | 割当モード ⇔ 切断点モード |
| E-09 | Ctrl+C / Ctrl+V | 選択中のノーツの割当パターンをコピー / カーソル位置に貼る |

## 6. 右クリック（テンポのメニュー）

どの列・どの物の上でも同じメニューが出る（選択は変えない）。位置は押した高さをグリッドに寄せた pulse（Shift / Alt は効かない）。

| 番号 | 項目 | 出る条件 |
|---|---|---|
| F-01 | ここで BPM を変える… | 常に |
| F-02 | この BPM 変更を消す | ちょうどその位置に BPM 変更があるとき |
| F-03 | ここに STOP を置く… | 常に |
| F-04 | この STOP を消す | ちょうどその位置に STOP があるとき |
| F-05 | 小節 N から拍子を変える… | 常に |
| F-06 | 小節 N の拍子変更を消す | その小節で拍子が変わっているとき（小節 0 以外） |
| F-07 | ここに小節線を足す / この小節線を消す | 小節線がない位置 / ある位置（小節 0 以外、手で小節線を持つ譜面） |

## 9. 今の実装で気になる点（直すときの候補）

操作感の見直しの参考に、実装を洗い出して気づいた不揃いを挙げる。

1. ~~ノーツを複数選んでも、ドラッグで動くのは押した 1 つだけ~~ → v0.13.2 で A-04b にした。長さの変更（A-08）と A-11 は押した 1 つだけのまま
2. Ctrl+クリックで、ノーツは選択から外せない（A-03）が、切断点は外せる（B-04）
3. ノーツの縦ドラッグは何も起きない（A-06）。押したときの見た目の変化がないので、失敗したように見える
4. ダブルクリックに意味があるのは、切断点モードの素材列（B-10）と BGA 列（D-04）だけ
5. 右クリックはどこでもテンポのメニュー。ノーツや切断点の上でも、それらの操作（割り当てを外す・消すなど）は出ない
6. カーソル（黄色の線）は、クリック・試聴・↑↓のたびに動くので、貼り付け先にしたい位置を保ちにくい
7. 見出しの行（列名）をクリックしても何も起きない（列の選択・折りたたみなどはない）
8. マウスを乗せただけでは見た目が変わらない（ホバーの表示がない）
