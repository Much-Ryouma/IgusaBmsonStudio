# 手動チェックリスト（GUI）

自動テストでは確かめにくい「見た目」と「実際の音」を、リリース前やマイルストーンの区切りで手で確認する。
結果は PR の説明などに `[x]` で残す。

- 準備: Windows で `IgusaBmsonStudio.exe` を起動する。手元の作品（完成品の例など）を 1 つ用意する
- 対象: M3（アレンジャー、波形ビュー、切断点編集、スライス試聴）、M4（譜面エディタ、タイミング）、M5（サイドカー、BGA、曲の情報、外部プレーヤー）

## 開く・保存

- [ ] 既存の bmson を開くと、素材ごとに 1 行ずつ並び、配置が波形付きで表示される（読み込み中は波形なし→数秒で表示）
- [ ] 日本語を含むフォルダ・ファイル名の譜面を開ける
- [ ] 何か編集するとタイトルに `*` が付き、保存すると消える。元に戻して保存時点に戻っても `*` が消える
- [ ] 素材ファイルが足りない譜面を保存すると、V04 の一覧が出て保存されない
- [ ] 保存したファイルを Pulsus で開き、編集前と同じように鳴る

## 新しい譜面と素材

- [ ] 「新しい譜面」で保存先・タイトル・BPM を入れて作成できる
- [ ] 「素材を取り込む」で譜面のフォルダ内の wav を選ぶと、コピーされずに行が増える
- [ ] フォルダの外の wav を選ぶと、コピーするか聞かれ、「はい」でフォルダにコピーされる。同名のファイルがあるときはエラーになり、上書きしない
- [ ] 行の空いた所をダブルクリックすると配置ができ、スナップ（ツールバー）の単位に乗る

## アレンジャー

- [ ] 配置のドラッグで移動できる。Shift で細かく、Alt でスナップなし、Ctrl で複製
- [ ] Delete で配置を消せる。元に戻すと切断点・ノーツも戻る
- [ ] Ctrl+ホイールで拡大縮小（マウスの下の位置がずれない）、Shift+ホイールで横スクロール、ホイールで行のスクロール
- [ ] 目盛りをクリックすると黄色のカーソルが動き、Space / F5 でそこから曲が鳴る。赤い再生位置が音と合っている
- [ ] M（ミュート）/ S（ソロ）が曲の再生に反映される

## 音切り

- [ ] 配置をダブルクリックすると、下の波形ビューにその配置が全体表示される
- [ ] 解析中は「解析中…」と出て、その間も画面が固まらない（数分のステムで確認）
- [ ] 感度スライダーを動かすと、点線の候補がすぐに（1 秒以内に）増減する
- [ ] 「適用」で候補が青い実線になる。アタック欠けの切断点は赤い
- [ ] 元に戻すと「適用」の前の状態に 1 回で戻る
- [ ] 波形のクリックで、そのスライスだけが鳴る。鳴り始めの遅れが気にならない（目標 30 ms）
- [ ] ←/→ で前後のスライスへ移りながら試聴できる
- [ ] ダブルクリックで橙の手動の切断点ができる。ドラッグで動かせる。自動の切断点を動かすと橙（手動）に変わる
- [ ] Shift+ドラッグで範囲選択し、Delete でまとめて消せる。先頭とノーツのある切断点は残り、その旨が表示される
- [ ] Q で選択した切断点がグリッドに寄る
- [ ] 線の色: 青=自動、橙=手動、灰=読み込み、赤=アタック欠け、点線=未適用の候補、薄い点線=適用すると消える自動の切断点

## 譜面エディタ（M4）

- [ ] 「譜面」タブで、左から 小節番号 / BPM 等 / SC・1〜7 / BGM 列 / 素材列 / 密度 が並ぶ。素材列の切断点は素材の色、割当済みは薄い
- [ ] 素材列の切断点をクリックすると試聴され、下の波形ビューにその配置と選択した切断点が表示される
- [ ] 1〜7 / S で割り当てると次の切断点へ進み、続けて打てる（「譜面 → 割り当てたら次の切断点へ進む」で止められる）
- [ ] 0 で割当を外すと、ノーツが消えて切断点が濃い色（BGM）に戻る
- [ ] ノーツを横にドラッグしてもタイミング（y）は変わらない。BGM 列にも置ける
- [ ] ノーツの上端か Shift+ドラッグでロングノーツになり、同じレーンの次のノーツと重ねて保存すると V05 で止まる
- [ ] 範囲選択 → Ctrl+C → 別の小節をクリック → Ctrl+V で、同じフレーズの繰り返しに割当が写る。切断点がない所は件数が表示される
- [ ] 「譜面」メニューのミラー / レーン入れ替え / ランダム（同じシードで同じ結果）が選択したノーツに効き、1 回の Undo で戻る
- [ ] 右クリックで BPM 変更・STOP・拍子（7/8 など）・小節線を追加・削除でき、左の列に表示される
- [ ] 音の入った配置の途中で BPM を変えると確認が出る。「時間を保つ」で試聴の音と切断点が合ったまま、「そのまま」で拍の位置が保たれる。「後で決める」にするとアレンジャーの配置に赤字の警告が出る
- [ ] Tab で切断点モードになり、素材列のダブルクリックで切断点を足し、ドラッグで動かせる
- [ ] 右下に総ノーツ数と total の目安が出る。密度の列が小節ごとのノーツ数に合っている
- [ ] アレンジャーの配置を右クリック →「位置を数値で指定」で 12:1 や pulse の数値で動かせる
- [ ] 作った譜面を保存して Pulsus で開き、割り当てたとおりに鳴る（LN、BGM 列、BPM 変化、STOP を含めて）

## サイドカー・BGA・曲の情報・外部プレーヤー（M5）

- [ ] 保存すると `<name>.ibs.json` ができる。閉じて開き直しても、切断点の青（自動）・橙（手動）の区別、音切りの設定、テンポ変更の警告が残っている
- [ ] `.ibs.json` を消して開いても bmson の内容で開ける（切断点はすべて灰色＝読み込み）
- [ ] 他のツールで bmson の配置を動かしてから開くと、対応の取れない数が通知され、間違った配置に色が付かない
- [ ] BGA 一覧に png / jpg を追加するとサムネイルが出る。動画は色の四角で出る
- [ ] 一覧で選んだ画像を BGA / LYR / POOR 列に置き、動かし、消せる。画像を一覧から消すとイベントも消え、元に戻すで戻る
- [ ] 「曲の情報」で全項目を入力して保存し、Pulsus（や beatoraja）の選曲画面にタイトル・アーティスト・レベル・バナーが出る
- [ ] 正方形のバナーを設定して保存すると、警告 V10 が出る（保存はされる）
- [ ] F7 で、初回はプレーヤーの設定が開き、設定後は Pulsus がカーソルの小節から再生される
- [ ] 未保存の変更があるときは `.~preview_<name>.bmson` が作られ、それが再生される。保存済みならそのファイルが再生される
- [ ] フォルダ名に空白や日本語を含む曲でも F7 で再生できる
- [ ] Pulsus で LN・STOP・BGA・BGM 列（x が 9 以上）が鳴る／表示されるかを確認し、結果を仕様書の §13 に書く
