# 画面の操作（自動テスト） (gui)

- 対象: `ArrangerWidget` / `WaveformSlicerWidget` / `SlicerPanel` / `ChartEditorWidget` / `TimelineScrollBar` / `StatisticsDialog` / `NullTestDialog` / `MainWindow`（`StudioController` 経由）
- テストコード: `tests/gui/StudioGuiTest.cpp`、`tests/gui/ChartEditorGuiTest.cpp`（`ibs_gui_tests`。ctest では `StudioGui` の 1 件として実行）
- 根拠: SPEC.md §6.2（配置）、§6.3（手動編集・試聴）、§6.4（譜面編集）、§6.10（統計）、§11.4（ヌルテスト）
- 画面を出さずに実行する（`QT_QPA_PLATFORM=offscreen`）。マウスとキーの操作は、実際のイベントをウィジェットに送って再現する
- 設定は一時フォルダの ini に書き、exe の横の `IgusaBmsonStudio.ini` には触れない
- 共通の前提: 120 BPM・resolution 240、スナップは 16 分（60 pulse）。素材 drums.wav（0.5 / 1.0 / 1.5 秒に打撃）を pulse 960 に配置。音声出力は偽物（1000 Hz）

## 何を保証するか

画面の操作が、意図した編集操作（app 層）に正しくつながっていること。
特に、スナップの効き方、選択、Undo の単位が画面から見て仕様どおりであること。
見た目（色・描画の崩れ）や実際に音が鳴るかは、手動のチェックリスト（[manual_checklist.md](manual_checklist.md)）で確認する。
