# 外部プレーヤーでのプレビューと BGA の操作 (app)

- 対象: `splitCommandLine` / `buildLaunchRequest` / `previewPositionAt` / `PreviewService` / `BgaCommands`
- テストコード: `tests/unit/app/PreviewServiceTest.cpp`、`tests/unit/app/BgaCommandsTest.cpp`
- 根拠: SPEC.md §6.7（外部プレーヤー）、§6.5（BGA）、§6.6（メタ情報）
- プロセスの起動とファイルの書き込みは偽物に差し替え、何が渡されるかを確かめる

## 何を保証するか

設定したコマンドテンプレートどおりに、空白を含むパスでも 1 つの引数としてプレーヤーに渡せること。
未保存の変更がある譜面は、譜面と同じフォルダの一時ファイルに書き出して渡すこと（素材の相対パスが解決できるように）。
BGA と曲の情報の変更が、1 回の Undo で戻ること。

## プレビュー (PRV)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| PRV-001 | `"C:\Program Files\Pulsus\Pulsus.exe" "{file}" -p  -m {measure}` / `a "" b` | 区切る | 引用符の中の空白は区切らない。連続した空白は 1 つ / 空の引数も残る |
| PRV-002 | テンプレート `"{exe}" "{file}" -p -m {measure} --at={pulse}/{seconds}`、ファイル `My Song/song [A].bmson` | 小節 12・pulse 11520・24 秒で組み立てる | プログラムは exe、引数はファイル（空白込みで 1 つ）、-p、-m、12、--at=11520/24.000。作業フォルダは譜面のフォルダ |
| PRV-003 | 小節線 0, 960, 1800（120 BPM） | 1800 / 非常に後ろ / -5 の位置 | 小節 2・3.75 秒 / 999 で止める（Pulsus の上限）/ pulse 0 |
| PRV-004 | `song/song.bmson`、変更なし → 素材を追加 | プレビュー 2 回 | 1 回目はそのまま渡す。2 回目は `song/.~preview_song.bmson` に書き出して渡す |
| PRV-005 | 実行ファイルの設定なし / 保存先なし / 起動に失敗 | プレビュー | どれも理由を返す。起動の失敗にはプログラム名が入る |

## BGA と曲の情報 (BGC)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| BGC-001 | 空の譜面 | movie.webm を 2 回追加、同じ位置に同じ画像を 2 回置く、同じ位置へ動かす → 960 へ動かす → 画像を削除 → 元に戻す | 2 回目の追加と、何も変わらない操作は履歴を増やさない。削除でイベントも消え、1 回の Undo で戻る |
| BGC-002 | 空の譜面 | 同じ曲の情報で更新 / バナーを変えて更新 | 履歴は増えない / 変わり、Undo の名前は「曲の情報」 |
