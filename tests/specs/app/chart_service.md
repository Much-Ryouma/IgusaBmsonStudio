# 譜面ファイルの開く・検証・保存 (app)

- 対象: `ibs::app::ChartService`（サイドカー、バナーの検証、プレビュー用の書き出しを含む）
- テストコード: `tests/unit/app/ChartServiceTest.cpp`
- 根拠: SPEC.md §6.8（出力前に検証し、エラーがあれば出力しない）、§8.1（GUI と CLI が同じユースケースを使う）

## 何を保証するか

GUI と CLI が共通で使う「開く・検証・保存」が、ファイルの読み書きと切り離して正しく動くこと。
検証エラーがある譜面は保存されないこと。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| APP-001 | 正しい bmson（読み込み時の通知あり） | 開く | 編集モデルが得られ、JSON と変換の両方の通知が含まれる |
| APP-002 | 読み込みで `BmsonFormatError` が起きる | 開く | 編集モデルはなく、エラーメッセージにファイル名が含まれる |
| APP-003 | 音素材ファイルがない譜面 | 保存する | 保存されない。V04 が返る。ファイルへの書き込みは行われない |
| APP-004 | 音素材がそろった譜面 | 保存する | 保存される。書き込まれた内容は編集モデルを書き出したもの |
| APP-005 | 未定義の mode_hint の譜面 | モード定義を探す | 見つからない（nullptr） |
| APP-006 | 開いた譜面の切断点を手動にし、配置に感度 0.8 の設定 | 保存して開き直す | サイドカーが bmson と同じ場所に書かれ、開き直すと手動の切断点と感度 0.8 が戻る |
| APP-007 | サイドカーが読めない・書けない | 開く / 保存する | bmson の内容で開き、通知 SIDECAR-UNREADABLE / bmson は保存され、警告 SIDECAR-UNWRITABLE |
| APP-008 | banner_image が 256×256 の画像 | 検証する | 警告 V10。画像は譜面のフォルダからの相対パスで調べる |
| APP-009 | 素材ファイルがない譜面 | プレビュー用に書き出す（exportCopy） | 検証エラー V04 を返しつつ書き出す。サイドカーは書かない |

# 完成品での往復テスト (external)

- テストコード: `tests/unit/external/SampleRoundTripTest.cpp`
- 実行条件: 環境変数 `IBS_EXTERNAL_SAMPLES_DIR` に bmson を含むフォルダを指定したときだけ実行する（未指定ならスキップ）
- 理由: 実際の作品はリポジトリに入れられないため、手元の作品で確認する

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| EXT-001 | フォルダ内（サブフォルダを含む）のすべての `.bmson` | 読み込み → 編集モデル → 書き出し → 読み込み | 再生内容が元と同じ（`describePlaybackDifferences` が空） |
| EXT-002 | EXT-001 と同じ | ノーツの数を比べる | 元のファイルで省略可能な BGM ノーツを除き、同じ数 |
