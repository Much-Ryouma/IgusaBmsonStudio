# 素材の読み込み、試聴、音切りのプレビュー (app)

- 対象: `AudioLibrary` / `PlaybackService` / `SlicingSession`
- テストコード: `tests/unit/app/AudioLibraryTest.cpp`、`PlaybackServiceTest.cpp`、`SlicingSessionTest.cpp`
- 根拠: SPEC.md §6.3（パラメータを変えるとリアルタイムで再検出、試聴、アタック欠けの表示）、§7.4（性能目標）
- 音声デバイスとファイルは偽物（`tests/unit/support/FakeAppPorts.hpp`）に差し替える。出力のサンプルレートは計算しやすい 1000 Hz にする

## 何を保証するか

素材は 1 回だけ読み込み、波形の縮小表示と立ち上がりの解析を使い回すこと（スライダーを動かすたびに読み直さない）。
試聴では、選んだスライス・配置・曲の範囲だけを鳴らし、再生位置を曲の時刻と素材の時刻で返せること。
音切りのプレビューは文書を変えず、「適用」で初めて 1 回の Undo 単位として反映されること。

## 素材の読み込み (AUL)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| AUL-001 | フォルダに bass.ogg だけがある | `bass.wav` を 2 回取得 | 拡張子を読み替えて bass.ogg を読む。読み込みは 1 回で、同じ実体を返す。モノラルと波形の縮小表示も用意される |
| AUL-002 | 素材ファイルがない | 2 回取得 → 取り消し（invalidate）→ 取得 | エラーに素材名が入る。ファイルを探すのは 1 回だけ（失敗も覚える）。取り消すと探し直す |
| AUL-003 | 素材がある | 既定 → 感度だけ変更 → 関数をエネルギーに変更して解析を取得 | 感度だけなら同じ解析を使い回す。関数を変えると解析し直す |
| AUL-004 | フォルダ A で読み込み済み | フォルダ B に切り替えて取得 | キャッシュを捨て、B のファイルを読む |

## 試聴 (PLY)

120 BPM・resolution 240 で、素材 a（2000 サンプル、値はサンプル番号 × 0.001）を pulse 480（1.0 秒）、素材 b（1000 サンプル、0.5 一定）を pulse 0 に置く。

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| PLY-001 | a の配置に offset 240 と 480 の切断点 | offset 240 のスライスを試聴 | 素材の 500〜1000 サンプルだけをステレオで鳴らす（先頭の値 0.5）。曲の時刻は 1.5 秒から |
| PLY-002 | PLY-001 の再生中に 250 フレーム進んだ | 再生位置を求める → 停止 | 曲の 1.75 秒、素材の 0.75 秒 → 停止後はなし |
| PLY-003 | a をミュート / a をソロ（ミュートより優先） | 曲を pulse 0 / 480 から再生 | b だけで 1000 フレーム / a だけで 2000 フレーム（10 フレーム目は 0.01）。曲の再生では素材の時刻はなし |
| PLY-004 | ファイルのない素材の配置 / 出力が開始できない | 配置を試聴 | どちらも開始せず、理由（素材名、出力のエラー）を返す。再生中の情報は残らない |

## 音切りのプレビューと適用 (SLS)

120 BPM・resolution 240 で、0.5 / 1.0 / 1.485 秒にノイズの打撃がある素材を pulse 0 に置き、offset 30 に古い自動の切断点を置く。

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| SLS-001 | 上記 | プレビュー | 立ち上がり 3 個、計画 240 / 480 / 720。置き換わる切断点は offset 30。文書と Undo 履歴は変わらない |
| SLS-002 | 上記 | プレビューを適用 → Undo | 切断点 0 / 240 / 480 / 720 → 1 回の Undo で 0 / 30 に戻る |
| SLS-003 | プレビューの後に配置を pulse 960 へ動かした | 適用 | 失敗し、理由を返す（グリッドへの寄せ方が配置の位置で変わるため）。切断点は変わらない |
| SLS-004 | 適用済み（1.485 秒は 1.5 秒のグリッドへ 15 ms 後ろに寄る） | アタック欠けの印を調べる → その切断点を手で動かす | 720 は印あり、240 は印なし → 動かすと手動になり、印は消える |
| SLS-005 | 配置ごとに設定（4 分グリッド）を保存 / ファイルのない素材の配置 | 設定を取得 / プレビュー | 保存した配置だけ 4 分、他は既定の 16 分 / プレビューできず、エラーに素材名が入る |
