# 編集の土台: Undo、配置と切断点の操作、素材の取り込み、表示範囲 (app)

- 対象: `EditorDocument` / `ArrangementCommands`（`placeAsset` ほか） / `AssetImportService` / `TimelineViewport` / `snapPulse`
- テストコード: `tests/unit/app/EditorDocumentTest.cpp`、`ArrangementCommandsTest.cpp`、`AssetImportServiceTest.cpp`、`TimelineViewportTest.cpp`
- 根拠: SPEC.md §6.1（素材は譜面からの相対パス）、§6.2（配置）、§6.3（手動編集）、§8.1（GUI はユースケースを呼ぶだけ）
- GUI を使わずに確かめられるよう、画面の操作はすべてここのクラスを通す

## 何を保証するか

1 回のユーザー操作が 1 回の Undo で元に戻ること。失敗した操作は何も変えないこと。
保存した状態に戻れば「未保存」の印が消えること。
素材は必ず譜面のフォルダからの相対パスになり、フォルダにある別のファイルを上書きしないこと。
タイムラインの拡大・縮小で、カーソルの下の位置がずれないこと。

## Undo と文書 (EDT)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| EDT-001 | 空の文書 | 素材を追加 → Undo → Redo | 追加 → 消える（Redo できる）→ 同じ ID で戻る。Undo の名前は「素材の追加」 |
| EDT-002 | kick.wav がある | 同じ名前を追加する操作（例外が出る） | 例外がそのまま伝わり、素材も Undo 履歴も変わらない |
| EDT-003 | 操作 → Undo した | 別の操作をする | Redo できなくなる |
| EDT-004 | Undo の上限 2 | 3 回操作して 3 回 Undo | 最初の操作の後の状態で止まる（古い履歴は捨てる） |
| EDT-005 | 操作した文書 | 保存済みにする → Undo → Redo | 未保存の印: 消える → 付く → 消える（保存した状態に戻ったため） |
| EDT-006 | リスナーを登録 | 操作・Undo・Redo の後に登録を外して Undo | 3 回だけ呼ばれる |
| EDT-007 | 履歴のある文書 | `charts/song.bmson` で置き換える | 履歴なし、未保存の印なし、譜面のフォルダは `charts`。パスのない文書のフォルダは空 |

## 配置と切断点の操作 (ARR)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| ARR-001 | pulse 960 の配置 | 曲の pulse 1200 に手動の切断点を追加 / 960（配置の先頭）に追加 | offset 240 の手動の切断点 / `std::invalid_argument`。Undo で消える |
| ARR-002 | pulse 1200 の切断点 | 同じ 1200 へ移動 / 1260 へ移動 | 履歴は増えない / offset 300、Undo の名前は「切断点の移動」 |
| ARR-003 | 先頭、ノーツ付き、ノーツなし 2 つの切断点 | 4 つまとめて削除 | ノーツなしの 2 つだけ消え、戻り値は 2。1 回の Undo で 4 つに戻る。消せるものがなければ履歴は増えない |
| ARR-004 | offset 240 の切断点（ノーツ付き）がある配置 | pulse 3840 に複製 | 先頭と 4080 の切断点ができる。ノーツは複製しない（重なりによる V05 を避ける） |
| ARR-005 | 切断点のある配置 | 同じ位置へ移動 / 配置を削除して Undo | 履歴は増えない / 切断点が同じ ID で戻る |
| ARR-006 | pulse 960 の配置に、曲の 1205・1320・1316 の切断点 | 先頭を含めて 16 分グリッド（60 pulse）にクオンタイズ | 1205 → 1200 だけ動き、戻り値 1。1320 はグリッド上、1316 は 1320 と重なるので動かさない、先頭は対象外。1 回の Undo で戻る |
| ARR-007 | pulse 960 の配置に手動の切断点 1200 | 素材を削除 → Undo | 素材・配置・切断点がなくなり、Undo の名前は「素材の削除」→ 1 回で元に戻る |
| ARR-008 | bass（960、切断点 1200）、lead と pad も 960 に配置 | bass の切断点を lead と pad に写す → Undo | 写した切断点は 2 つ、切断点は全部で 6 つ。Undo の名前は「切断点のコピー」→ 1 回で 4 つに戻る |
