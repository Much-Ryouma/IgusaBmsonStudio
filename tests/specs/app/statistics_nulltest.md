# 譜面の統計とヌルテスト (app/statistics・app/nulltest)

- 対象: `playableNoteStatistics` / `bgmStatistics` / `densityOf` / `levelOf` / `computeChartStatistics` / `NullTestService` / `loadProjectAudio` / `withRecentFile` / `withoutRecentFile`
- テストコード: `tests/unit/core/chart/ChartStatisticsTest.cpp`、`tests/unit/app/NullTestServiceTest.cpp`、`tests/unit/app/RecentFilesTest.cpp`
- 根拠: SPEC.md §6.10（統計）、§11.4（ヌルテスト）、§6.9（最近使った譜面）

## 何を保証するか

譜面の部分（鍵盤のノーツ）・BGM の部分・合計それぞれについて、ノーツの種類と数、1 秒あたりの最大密度とその位置、平均密度、再生時間、音量を出せること。
ヌルテストでは、配置どおりの音と「書き出した bmson の鳴り方」を比べ、違う区間を小節番号つきで返し、比べられない状態を合格にしないこと。

## テスト項目

### 統計 (STA)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| STA-001 | beat-7k。240 にレーン 1 のノーツが 2 素材ぶん（レイヤー）、480 にレーン 2 の LN、720 と 960 にスクラッチ（960 は LN）、1200 にレーン 12（BGM 列） | ノーツと BGM を数える | 総数 4（レイヤーは 1 つ）、通常 1、LN 1、スクラッチ 1、スクラッチ LN 1、レーン 8 は 2。BGM のスライス 3（各配置の先頭 2 つと 1200）、BGM 列のノーツ 1 |

### ヌルテスト (NTS)

素材は 8000 Hz のノイズ（bass と lead、各 2 秒）。bass を 0、lead を 480 に配置し、bass の 240 にレーン 1、lead の 240 にレーン 14（BGM 列）。

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| NTS-001 | 上記 | 内蔵の再生で比べる | 完了・合格、差は -60 dB 未満、違う区間なし |
| NTS-002 | bass の 240 のスライスにレーン 2 も追加 | 内蔵の再生で比べる | 完了・不合格。最も違う区間は小節 0（pulse 0 以上） |
| NTS-003 | プレーヤーの書き出し結果として、BGM 列を戻した bmson の音に 0.1 秒の無音を足したものを用意 | `Pulsus.exe` で比べる | ずれ 100 ms（0.2 ms 以内）、合格。起動の引数は `chart/.~nulltest_song.bmson --render chart/.~nulltest_song.wav` |
| NTS-004 | プレーヤーが終了コード 3 を返す / `missing.wav` の配置を追加 | プレーヤーで比べる / 内蔵の再生で比べる | 未完了でエラーに「3」を含む / 見つからない素材に `missing.wav` |
| NTS-005 | 素材が 1 つも読めない | 内蔵の再生で比べる | 未完了・不合格でエラーあり（無音どうしの比較を合格にしない）。見つからない素材に bass と lead |
