# 音声の読み込み (infra/audio) と音切りのユースケース (app)

- 対象: `ibs::infra::decodeAudioFile` / `ibs::app::SlicingService`
- テストコード: `tests/unit/infra/audio/AudioFileDecoderTest.cpp`、`tests/unit/app/SlicingServiceTest.cpp`
- 根拠: SPEC.md §6.2（素材の取り込み）、§6.3（音切り）

## 何を保証するか

音声ファイルを、日本語を含むパスでも読み込めること。
GUI と CLI が共通で使う「配置を音切りする」操作が、素材の探索から切断点の追加まで正しく動くこと。

## 音声の読み込み (DEC)

テスト用の wav はテストの中で書き出す。ogg の読み込みは、完成品の例のステムで手元で確認する（著作物のためリポジトリに入れない）。

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| DEC-001 | 16 bit・ステレオ・44.1 kHz の wav（既知の値） | 読み込む | サンプルレート、チャンネル数、フレーム数、値（±1/32767）が一致 |
| DEC-002 | 日本語のフォルダ名・ファイル名の wav | 読み込む | 読み込める |
| DEC-003 | 存在しないファイル | 読み込む | `AudioDecodeError` |
| DEC-004 | 中身がテキストのファイル（拡張子 .wav） | 読み込む | `AudioDecodeError` |

## 音切りのユースケース (SLC)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| SLC-001 | ノイズ 4 発の音声、配置 1 つ | 音切りする | 自動の切断点が 3 つ追加される（先頭の 1 発は配置の先頭に統合） |
| SLC-002 | 素材ファイルが見つからない | 音切りする | 失敗し、素材名を含むエラーになる |
| SLC-003 | 1 回目の結果の切断点 1 つにレーンを割り当てた | 無音の音声でもう一度音切りする（検出 0 個） | 割り当てた切断点だけ残り、ほかの自動の切断点は消える |
