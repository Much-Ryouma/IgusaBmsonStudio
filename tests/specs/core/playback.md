# 試聴の範囲とミックス (core/playback)

- 対象: `sampleOffsetInPlacement` / `sliceRange` / `placementEndPulse` / `renderRange` / `renderMix` / `renderBmson` / `compareRenders`
- テストコード: `tests/unit/core/playback/PlaybackRangeTest.cpp`、`tests/unit/core/playback/BmsonRendererTest.cpp`
- 根拠: SPEC.md §6.3（スライスの試聴）、§8.2（ドメインモデル）、§11.4（ヌルテスト）
- 計算を追いやすくするため、サンプルレート 1000 Hz・120 BPM・resolution 240（1 拍 = 240 pulse = 0.5 秒 = 500 サンプル）を使う

## 何を保証するか

切断点からスライスの範囲（素材の何サンプル目から何サンプル目まで）を、BPM 変化を考慮して求められること。
曲全体の試聴では、各配置の素材を配置の時刻から重ね、出力のサンプルレートに合わせて鳴らせること。

bmson をプレーヤーと同じ解釈（同じ y のノーツは 1 つのスライス、`c=false` で頭から鳴らし直す、同じ y にレーンのノーツがあれば BGM のノーツは鳴らさない）で鳴らせること。
2 つの音を、ずれと音量の違いを合わせてから引き算し、どこがどれだけ違うかを区間ごとに出せること。

## テスト項目

### 試聴の範囲とミックス (RNG)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| RNG-001 | pulse 480 の配置、offset 240 と 720 の切断点、素材 3000 サンプル | 各切断点のスライス範囲 | 先頭 0〜500、240 は 500〜1500、720 は 1500〜3000（最後は素材の終わりまで）。素材が 1200 サンプルしかなければ 1200〜1200（空） |
| RNG-002 | pulse 480 から 60 BPM、pulse 240 の配置 | pulse 720 の素材内の位置 | 1500 サンプル（240→480 が 0.5 秒、480→720 が 1.0 秒）。配置より前は 0 |
| RNG-003 | pulse 960 の配置、1.5 秒の素材 | 配置の終わりの pulse | 1680（1.5 秒 = 720 pulse） |
| RNG-004 | 同じ 0.25 の直流素材を pulse 0（音量 1）と 240（音量 2）に配置 | 0.25〜1.0 秒をミックス | ステレオ 750 フレーム。先頭は 0.25、0.55 秒は 0.25 + 0.5 = 0.75 |
| RNG-005 | 500 Hz の素材 0,1,0,1,0 | 1000 Hz で 6 ms 分ミックス / 出力 0 Hz | 0, 0.5, 1 …（間を線形補間）/ `std::invalid_argument` |
| RNG-006 | 1000 Hz ステレオ 4 フレーム（L 0.1〜0.4、R は符号反転） | 1〜3 フレーム目を 1000 Hz / 2000 Hz で取り出す、素材の外まで指定 | 0.2,-0.2,0.3,-0.3 / 4 フレームで間は補間（0.25）。最後のフレームの先は直前の値を使う / 素材の終わりで切れて 1 フレーム |

### ヌルテスト (NUL)

素材は 8000 Hz のノイズ（2 秒の bass と 1.5 秒の lead）。bass を pulse 0 と 960、lead を 480 に配置し、切断点とノーツを数か所に置いた曲を使う。
「正解」は配置どおりに素材を重ねた音（`renderMix`）、「比べる音」は書き出した bmson を鳴らした音（`renderBmson`）。

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| NUL-001 | 上記の曲 | 正解と bmson の音を比べる | ずれ 0、音量の倍率 1、差は -60 dB 未満（切断点で切って並べ直しても配置どおりに鳴る） |
| NUL-002 | 1 つのスライスにレーン 1 と 2 のノーツ | 比べる | 差は -20 dB より大きい。最も違う区間は 0.5 秒付近（そのスライスが 2 回重なって鳴るため） |
| NUL-003 | 正解の先頭に 0.15 秒の無音を足し、音量を半分にした音 | 比べる | ずれ 0.15 秒（1 サンプル以内）、倍率 2、差は -60 dB 未満 |
| NUL-004 | 配置の途中に STOP（pulse 360 から 120 pulse）と、その後ろの切断点 | 比べる | 差は -60 dB 未満（STOP は正解と bmson の両方を同じだけ後ろへずらすため、差にならない） |
| NUL-005 | 8000 Hz と 16000 Hz の音 | 比べる | `std::invalid_argument` |
| NUL-006 | 30 秒の小さな音の 20〜24 秒に大きな音を重ね、先頭に 1.9 秒の無音を足した音 | 比べる | ずれ 1.9 秒（1 サンプル以内）、差は -60 dB 未満（粗いずれは FFT で曲全体から、細かいずれは最も大きい 8 秒で求める） |
