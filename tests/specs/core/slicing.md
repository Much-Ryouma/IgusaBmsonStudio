# 音切り (core/audio, core/slicing, core/timing)

- 対象: `mixToMono` / `fftInPlace` / `detectOnsets` / `BeatGrid` / `planCuts` / `applyCutPlan` / `timeSignatureForBarLength`
- テストコード: `tests/unit/core/audio/AudioBufferTest.cpp`、`tests/unit/core/slicing/*Test.cpp`、`tests/unit/core/timing/BarLinesTest.cpp`
- 根拠: SPEC.md §6.3（音切り）、§4.1（完成品の例）
- テスト用の音声は、すべてテストコードの中で合成する（`tests/unit/support/SyntheticAudio.hpp`）

## 何を保証するか

音の立ち上がりを、切断点として使える精度（数 ms 以内）で見つけられること。
見つけた立ち上がりを、拍子・BPM 変化を考慮したグリッドに寄せ、アタックが前のスライスに入る箇所を警告できること。
自動検出をやり直しても、手で直した切断点やレーンを割り当てた切断点が消えないこと。

## 立ち上がりの検出 (ONS)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| ONS-001 | 打楽器風のノイズ 8 発（間隔 0.25 秒）、薄い背景ノイズ | 既定の設定で検出 | 8 個すべてを ±3 ms 以内で検出し、余分な検出はない |
| ONS-002 | 隙間なく音程が変わる正弦波 6 音（レガート） | スペクトルフラックスで検出 | 6 音すべてを ±10 ms 以内で検出 |
| ONS-003 | 無音 | 検出 | 0 個 |

| ONS-005 | 10 ms 間隔の 2 発 | 最小間隔 30 ms で検出 | 1 個にまとまる |
| ONS-006 | -70 dBFS 程度の小さなノイズ 4 発 | 無音ゲート -60 dB で検出 | 0 個 |
| ONS-007 | ノイズ 1 発 | プリロール 5 ms で検出 | プリロールなしより 5 ms（±0.5 ms）手前 |
| ONS-008 | 感度 1.5、フレーム長 1000 | 検出 | `std::invalid_argument` |

## グリッドとクオンタイズ (QNT, CUT)

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| QNT-001 | resolution 240、小節線 0, 960, 1800（2 小節目が 7/8）、8 分 3 連グリッド（80 pulse 間隔） | pulse 1830 に最も近いグリッド | 1800（7/8 小節の次の小節頭から数え直す。曲頭から数えると 1840 になる） |
| QNT-002 | 小節線 0, 960（最後の小節以降は 960 ごとと見なす） | pulse 2165 に最も近いグリッド | 2160 |
| CUT-001 | 120 BPM、res 240、配置 0。グリッドの 4 ms 後ろに立ち上がり | 16 分グリッドで計画 | グリッドに寄る。late は約 -4 ms |
| CUT-002 | CUT-001 と同じで、強さ 0.5 | 計画 | グリッドとの中間に寄る |
| CUT-003 | グリッドから 30 ms 離れた立ち上がり、許容幅 20 ms | 計画 | 寄せない。立ち上がりより後ろにならないよう切り捨てる |
| CUT-004 | グリッドの 15 ms 手前に立ち上がり | 計画 | グリッドに寄せた結果、アタック欠け（late > 10 ms）として印が付き、V09 が出る |

| CUT-006 | 配置 960、BPM 60 | 0.5 秒の立ち上がりを計画 | offset 120（配置の先頭からの相対位置） |
| APL-001 | 自動の切断点（割当なし・割当あり）、手動の切断点がある配置 | 計画を適用 | 割当なしの自動の切断点だけ消える。既存と同じ位置は追加しない |
