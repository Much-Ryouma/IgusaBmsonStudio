# 編集モデル (core/model)

- 対象: `ibs::core::Project`
- テストコード: `tests/unit/core/model/ProjectTest.cpp`
- 根拠: SPEC.md §8.2（ドメインモデル）

## 何を保証するか

素材・配置・切断点・ノーツに、重複しない ID が振られること。
配置には必ず先頭の切断点（offset 0）があり、ノーツは y を自分で持たず切断点を通じて位置が決まること。
不正な操作（重複、存在しない ID、負の値）は受け付けないこと。

## テスト項目

| ID | 前提 | 操作 | 期待結果 |
|---|---|---|---|
| PRJ-001 | 空のプロジェクト | 素材・配置・切断点・ノーツを1つずつ追加 | すべての ID が有効で、互いに異なる |
| PRJ-002 | 素材 1 つ | pulse 960 に配置を追加 | offset 0 の先頭切断点が自動で作られる |
| PRJ-003 | pulse 960 の配置に offset 240 の切断点 | 切断点の絶対位置を求める | 1200 |
| PRJ-004 | 同名の素材がある | 同じ名前で素材を追加 | `std::invalid_argument` |
| PRJ-005 | offset 240 の切断点がある | 同じ配置に offset 240 を追加 | `std::invalid_argument` |
| PRJ-006 | 配置がある | offset 0 または負の切断点を追加 | `std::invalid_argument`（offset 0 は先頭切断点の位置） |
| PRJ-007 | 切断点がある | レーン 0 にノーツを追加 | `std::invalid_argument`（割当なしの切断点が BGM になるため） |
| PRJ-008 | レーン 3 のノーツがある切断点 | 同じ切断点のレーン 3 に追加 | `std::invalid_argument` |
| PRJ-009 | 空のプロジェクト | 存在しない ID の素材を参照 | `std::invalid_argument` |
| PRJ-010 | 切断点がある | 同じ切断点のレーン 1 とレーン 7 にノーツを追加 | 両方追加できる（同じスライスを複数レーンに割り当てられる） |
| PRJ-011 | 先頭の切断点、ノーツのある切断点、ノーツのない切断点 | 削除する | 先頭とノーツのあるものは `std::invalid_argument`、ノーツのないものは消える |
| PRJ-012 | pulse 960 の配置、offset 240 の自動の切断点にレーン 3 のノーツ | offset 300 へ動かす | 絶対位置 1260、手動の切断点になる（再検出で消されない）。ノーツは同じ ID のまま付いてくる |
| PRJ-013 | offset 240 と 480 の切断点 | 先頭を動かす / 240 を 0 へ / 240 を 480 へ | すべて `std::invalid_argument`。位置は変わらない |
| PRJ-014 | pulse 0 の配置、offset 240 の切断点 | 配置を 1920 へ動かす / -1 へ動かす | 先頭 1920・切断点 2160（offset なので一緒に動く）/ `std::invalid_argument` |
| PRJ-015 | 同じ素材の配置 2 つ、それぞれノーツ付きの切断点 | 片方の配置を削除 | その配置の切断点とノーツだけ消える。もう一方と素材は残る |
| PRJ-016 | offset 720 → 240 の順に追加した切断点、別素材の配置 | 配置の切断点一覧 | 先頭、240、720 の順。別の配置の切断点は入らない |
